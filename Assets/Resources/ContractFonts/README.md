# Contract signature typeface

Allura Regular by Robert Leuschke / The Allura Project Authors.

Unmodified font from https://github.com/googlefonts/allura at commit `38a78b41510a10b1129c50fa5177b642bd2b4a19`, `fonts/ttf/Allura-Regular.ttf`.

Licensed under SIL Open Font License 1.1. Keep `OFL.txt` with the font when redistributing. The copy inside Resources is included with the game; no online font download or installed system font is required at runtime.

`ContractUIManager` creates a dynamic TextMesh Pro font from this source and uses existing game font fallbacks for unsupported characters. Only the handwritten signature uses Allura; the printed account name and agreement remain in the game's readable UI font.
