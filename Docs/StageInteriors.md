# Director Tablet interiors

Coffee Interior now reads Model, Position, Size, Scale and Rotation from the flagged Coffee Interior entry in ProductModels > Backdrops And Interiors. Position is a world-space offset after the existing backdrop alignment; the Coffee Interior offset is additional to the backdrop offset. Size uniformly multiplies the fitted interior, then Scale controls individual axes. Existing coffee size/rotation values were copied into the entry; legacy standalone fields are hidden fallbacks. Selection still uses the original Coffee Interior tablet option and ownership ID 2.

Select Assets/Resources/ProductModels.asset and edit Coffee Interior Scale X, Y, and Z independently. Each value multiplies the model's local axis, like Transform Scale; axes follow Coffee Interior Rotation. 1 keeps that axis unchanged; 0.8 makes it 20% smaller; 1.2 makes it 20% larger. Values are clamped to at least 0.01 at placement. These multipliers apply after automatic fitting, Preserve Coffee Interior Scale, and Coffee Interior Max Height, so enlarging can exceed those initial limits. The model is then centred and grounded, and its colliders and interaction targets follow the resulting geometry. Reapply the set through the tablet (switch to another set and back) to see edits; existing instances do not update live. Edit outside Play Mode to keep the setting.

Actor direction: the tablet places/repositions actors (T); it does not issue performance or walking cues. ActorMegaphoneItem selects actors with LMB. With an actor selected, aim at a stool or machine and click LMB to assign that exact visible Contract4Interactable; the held guide shows the available command. O stops/restores, R turns, Z/X/C cue poses, arrows nudge, B/N set walk marks, K rehearses, J resets and H clears walking. ActorBot owns the procedural pose and suspends walking while assigned. Switching to the camera keeps the action running; CubeActor.BeginTake restarts animation timing for each take. Existing pose metadata carries Sitting/Using Machine without changing grading or save schemas. CampaignLevelManager teaches megaphone direction after tablet placement.

BUY SET saves career ownership (OwnedInterior.0/1/2); USE SET places one owned set. Switching owned sets is free. Preview/Cancel restores the previous set, and Clear Stage preserves ownership.

Plain Backdrop costs 500 B, Cafe Corner costs 2,000 B, and Coffee Interior costs 2,750 B. Earlier levels retain ADD WALL.

StageInterior.Furnish uses ProductModels.coffeeInterior for the complete Coffee Interior set. It fits the imported room to the backdrop footprint, grounds it, and disables the replaced backdrop renderers and colliders. The ownership root remains intact for preview, purchase, selection and clearing. Cafe Corner still uses procedural furniture. Imported mesh colliders leave walkable spaces open; set dressing has no product/actor grading markers.

The current CoffeeInterior.fbx includes mesh geometry. Preserve its asset GUID. Gameplay and visual verification of the full-size set remain pending.

Plane.001 contains walls, counters, shelves, and other dressing. Runtime wall stretching is removed because moving only part of this mesh distorts adjoining faces and trim. Wall height is authored in Blender; Coffee Interior Scale X/Y/Z controls the entire set. The legacy back-wall multiplier is hidden and ignored. Reapply the set to discard any previously generated distorted mesh.

SingleStudio environment sizing is controlled by ProductModelCatalog.SingleStudioEnvironmentScale (currently 0.7), including root positions and the player's starting position. Player/actor height remains 1.85 m. ProductModelCatalog.SingleStudioEnvironmentScale must match the scene. DirectorTerminal applies it to previews, purchased sets and practice walls, then fits and centres the screen footprint inside 90% of the stage before grounding. Imported coffee interiors fit all three dimensions, with the catalog height cap (currently 3.145 m); preserveCoffeeInteriorScale prevents enlarging a smaller revised FBX. Procedural cafe furniture is reduced relative to the previous 1.85/3 layout. Product and actor dimensions remain human-sized.


During Level 4 actor practice, non-plain set previews and placement create only ProductModels.practiceChair. Coffee machines remain available in normal contract interiors. Chair height, rotation, and seat offset are editable in ProductModels. Both player and actor seating use its Seat Anchor instead of the top of the chair back. CoffeeInterior Read/Write is enabled for material-based seat and machine targets.
